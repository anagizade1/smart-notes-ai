# 🧠 Smart Notes AI

Smart Notes AI is a simple AI-powered study assistant that helps users understand and learn from text more efficiently.

## 🚀 Features
- 📌 Text summarization
- 🔑 Keyword extraction
- 🎭 Tone detection
- ❓ Quiz question generation
- 📚 Study tips
